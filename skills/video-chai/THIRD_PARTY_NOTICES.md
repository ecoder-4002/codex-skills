# Third-party notices

VideoChai invokes the following tools as external, separately installed programs or Python packages. Their code is not vendored in this repository.

- [yutto](https://github.com/yutto-dev/yutto), pinned to `2.3.0` for public Bilibili media preparation, GPL-3.0.
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) for anonymous public Douyin and X/Twitter media preparation, Unlicense.
- [Playwright](https://github.com/microsoft/playwright-python) for the isolated public-page Douyin fallback, Apache-2.0.
- [FFmpeg](https://ffmpeg.org/) for local media conversion and frame extraction; the applicable license depends on the installed build.
- [mlx-whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper) or [faster-whisper](https://github.com/SYSTRAN/faster-whisper) for local transcription.
