# VideoChai 60 秒介绍

## 屏幕与口播

| 时间 | 屏幕 | 口播 |
|---|---|---|
| 0–8s | 在 Agent 里粘贴一条 B 站或抖音链接 | 这是 VideoChai：给它一条 B 站或抖音链接就行。 |
| 8–18s | 补一句要求：“重点看产品演示” | 你可以附带自己的分析要求，不写也有默认完整拆解。 |
| 18–32s | 快速显示：临时取媒体 → 本机转录 → 关键帧 → 结构化 | 它会临时取得公开视频，在本机转录，再结合关键帧理解画面。 |
| 32–44s | 打开生成的飞书文档 | 最后直接生成一篇飞书文档，来源链接和你的原始要求都会保留。 |
| 44–54s | 新环境首次运行 doctor，Agent 列出缺失项 | 分享给别人后，他的 Agent 会先自检，带着安装依赖和完成飞书授权。 |
| 54–60s | 展示 Skill 文件夹与一句调用语 | 把 Skill 装进 Agent，然后说：“拆解这条视频，生成飞书文档”。 |

## 展示用调用语

```text
拆解这条视频，重点看产品演示和可复用方法，生成飞书文档：
https://www.bilibili.com/video/BV...
```
