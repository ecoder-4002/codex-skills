# VideoChai 60 秒介绍

| 时间 | 屏幕 | 口播 |
|---|---|---|
| 0–10s | 粘贴 B站或抖音视频链接 | 给 Agent 一条视频链接，让它下载或者总结。 |
| 10–22s | 输入“下载这个”，展示本地视频 | 只想要视频，直接保存到本地，不用启动转录。 |
| 22–38s | 输入“总结方法”，展示转录和关键帧 | 想了解内容，它会在本机转录，并结合实际画面提炼要点。 |
| 38–50s | 展示对话中的总结与本地 Markdown | 总结保留来源和时间点，也可以和视频一起保存。 |
| 50–60s | 展示安装链接和依赖检查 | 把 Skill 装进 Agent，先检查需要的依赖，就可以用视频链接开始。 |

展示用调用语：

```text
下载并总结这个视频，重点提炼可复用的方法：<公开视频链接>
```
