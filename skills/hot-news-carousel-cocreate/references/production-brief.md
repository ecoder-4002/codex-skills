## Mother draft

先用连贯新闻稿写清以下内容，再拆页：

1. 发生了什么；
2. 事情的背景；
3. 核心事实和关键变化；
4. 关键人物、产品或机制；
5. 为什么形成热点；
6. 对用户或行业的影响；
7. 争议、不确定性与下一步。

## Publication description

- 文件：`video-description.md`、`video-description.txt`
- 发布标题：
- 标题独立发布时如何成立：
- 标题与封面合并出现时增加了什么信息：
- 建议长度：500-900 个中文字符，按事件复杂度调整

- 最后五个标签：`#标签1 #标签2 #标签3 #标签4 #标签5`

两个文件必须以同一个发布标题开头：Markdown 使用 `# 标题`，TXT 使用无 Markdown 标记的纯文本标题。标题必须点明主体或事件，保证文字稿脱离图文时也能独立成立；与图文一起发布时，应补充语境或核心矛盾，不要机械重复封面。文字稿必须来自同一份母稿和事实账本，可以比成图更详细，但不能把 `一方主张` 写成独立事实，也不能纳入尚未解决的 `待确认` 信息。最后一个非空行必须只有五个相关标签。

## Final checks

### 事实

- [ ] 每个关键事实都有来源
- [ ] 日期、人物、产品、数字和引用已复核
- [ ] 指控、否认、判决和分析没有混写
- [ ] `待确认` 内容没有被画成事实
- [ ] `sources.md` 包含关键说法的可点击链接

### 内容

- [ ] 每页回答一个问题并推进故事
- [ ] 没有为了凑页数重复信息
- [ ] 正文为自然段，不是PPT要点堆积
- [ ] `copy.md` 与成图逐字一致
- [ ] 已生成比成图更详细、可直接发布的文字稿
- [ ] 两个发布文案文件均以同一个自足标题开头
- [ ] 发布标题脱离图文可以独立成立，与封面合并时不机械重复
- [ ] `video-description.md` 与 `video-description.txt` 内容一致
- [ ] 文字稿沿用同一事实账本并保留归因和不确定性
- [ ] 文字稿最后一个非空行恰好包含五个相关标签，且后面没有其他内容

### 视觉

- [ ] 封面同时突出标题与真实热点主角
- [ ] 后续每页图片与正文直接相关
- [ ] 人物只在真正相关的页面出现
- [ ] 中文无错字、乱码或意外文字
- [ ] 已记录本期 `account_attribution` 的具体值或明确标记为未配置
- [ ] 若已配置，每一页都包含准确署名；若未配置，没有出现占位符或虚构账号
- [ ] 署名位置统一并位于安全区内，没有被页码、平台控件或裁切遮挡
- [ ] 图片内无虚构日期、案号、UI或产品细节
- [ ] 所有PNG均为1080 x 1440
- [ ] 手机尺寸下可读

### 交付

- [ ] 输出文件夹包含 `brief.md`、`copy.md`、`video-description.md`、`video-description.txt`、`sources.md` 和全部PNG
- [ ] 已提供可点击的绝对文件夹地址
